returns number of found maxima and array local_maxima of local maximums of requested rank, where rank defins a region [cols-rank, cols+rank].

Assumes that cols > 2*rank...

1-d array of local maxumum of (uint16) values of data shape, with 0/+1/+2 for bad/non-maxumum/maximum in rank region.

Parameters
[in]data- pointer to data array
[in]mask- pointer to mask array; mask marks bad/good (0/1) pixels
[in]cols- number of columns in 1d array
[in]stride- index increment between neighbour elements. Makes sence for n-d arrays
[in]rank- radius of the square region in which central pixel has a maximal value
[out]local_maxima- pointer to the array local_maxima

Map of local maximum is a 2-d array of (uint16) values of data shape, with 0/+1/+2/+4 for non-maximum / maximum in column / maximum in row / minimum in square of radius rank.

returns map of local maximums for 2-threshold algorithm.

Map of local maximum is a 2-d array of (uint16) values of data shape, with 0/+1/+2/+4/+8 for masked / <thr_low / >thr_low && <thr_high / >thr_high / local maxima in runk-square +16 < -thr_low

[in]cols- number of columns in all 2-d arrays
[in]rank- radius of the square region in which central pixel has a maximal value
[in]thr_low- low threshold on intensity
[in]thr_high- high threshold on intensity
[out]map- pointer to map of local maximums
