Detailed Description

Runs the data reduction on the GPU for PGPDrp: loads the reducer library named by the reducer kwarg, creates one ReducerAlgo per worker, and passes buffer indices in and ReducerTuple results out through per-worker queues.

With graph algorithms, and without HOST_LAUNCHED_REDUCERS, each worker is a self-relaunching CUDA graph fed by device ring queues.

Create one stream per worker in green_ctx and load the algorithms (aborting on failure).

Then create the reduce buffers (header space plus the larger of payloadSize() and maxTrSize less the header) and the per-worker queues, state and return-code words and metric counters.
