Detailed Description

Opens a libfabric fabric and domain for a node and service, and keeps the list of memory regions registered in that domain.

Resolve node and service with getaddrinfo() and fi_getinfo(), then open the fabric and domain; up() reports success.

If hints is null, a default Info is created and its hints are owned (and later freed) by this object.
