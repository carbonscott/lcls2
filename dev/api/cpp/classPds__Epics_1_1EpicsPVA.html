Detailed Description

Client of one EPICS PV over pvAccess or Channel Access.

It connects asynchronously, gets the value once connected and, if a PVMonitorCb is given, then monitors the PV and calls its updated() for each update. getScalarAs() and related methods read the latest value; the put methods block until the put ends.
