◆ MetricType

enum class Pds::MetricType
strong

Kind of a metric registered with MetricExporter.

Enumerator
Gauge 

Value read by the callback at each scrape, exported as a gauge.

Counter 

Value read by the callback at each scrape, exported as a counter.

Rate 

Rate per second of the callback value since the previous scrape (negative changes give 0), exported as a gauge.

Constant 

Fixed value set by constant(), exported as a counter (per the comment, only for constant()).

Histogram 

A PromHistogram created by histogram().

Float 

Double value from a callback that reports whether it is valid, exported as a gauge.
