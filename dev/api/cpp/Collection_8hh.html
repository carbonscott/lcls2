◆ checkResourceLimits()

bool checkResourceLimits ( )

Check that the hard MEMLOCK limit is unlimited and the hard RTPRIO limit is 99, and raise the soft limits to the hard ones.

Returns true on a fatal problem (MEMLOCK inadequate or not settable, or a getrlimit() failure), else false.
