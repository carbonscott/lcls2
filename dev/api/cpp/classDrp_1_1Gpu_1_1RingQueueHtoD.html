Detailed Description

template<typename T>
class Drp::Gpu::RingQueueHtoD< T >

Lock-free ring of values of type T with one producer on the host (push()) and one consumer on the GPU (pop()).

The values and the head and tail counters are in pinned host memory; one slot always stays empty. Used by Reducer for the per-worker input queues of buffer indices.
