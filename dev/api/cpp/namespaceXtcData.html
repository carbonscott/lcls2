Detailed Description

Namespace of the XTC data-format classes (Xtc, Dgram, TypeId, Src, NamesId, ShapesData, DescData, iterators, ...).

Namespace of the xtcdata library (XTC datagram types); psdaq headers only forward-declare parts of it.

Class to support scanning of python-implemented detector configurations.

Namespace of the XTC data-format classes, defined in the xtcdata package; only Dgram is forward-declared here.

Assumes python module named <detType>_config.py with functions: <detType>_scan_keys(json_str) <detType>_update (json_str)

Typedef Documentation

◆ NamesLookup

typedef std::unordered_map<unsigned,NameIndex> XtcData::NamesLookup

Map from a NamesId value (as unsigned) to the NameIndex built from the matching Names xtc.

Per the comment above, it links the Names xtc of the Configure transition with the ShapesData xtc of each event. operator[] on a missing key inserts an empty NameIndex, whose names() throws.
