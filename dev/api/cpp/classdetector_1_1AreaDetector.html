Detailed Description

Base class for area detectors.

Config and data fields are read through a stored ConfigIter; calibration constants and geometry are forwarded to a CalibPars object created on first use with calib::getCalibPars(detname). Many virtual methods are defaults that only log a warning asking for re-implementation in a derived class.
