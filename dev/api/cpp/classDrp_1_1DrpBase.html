Detailed Description

Common machinery of a DRP process: TEB and MEB contributors, the TEB result receiver, the trigger primitive, Prometheus metrics, and the handling of the connect, configure, run and chunking transitions.

MemPool &  pool,
Detector &  det,
ZmqContext &  context 
)

Create the Prometheus exposer (port offset from the lowest laneMask bit and the numeric suffix of the device name), create the TEB and MEB contributors from para, and connect the inproc://drp PAIR socket.

Also stat()s the output directory and appends the pva_addr kwarg to EPICS_PVA_ADDR_LIST.
