Detailed Description

Prometheus collectable holding named metrics whose values come from callbacks evaluated at each scrape (Collect()).

Adding a metric with an existing name replaces it.

Register a histogram metric name with numBins buckets of width binWidth starting at binMin and return it for observe() calls.

Note that, unlike add() and addFloat(), this does not append a Float callback slot, so the internal per-metric vectors can get out of step.
