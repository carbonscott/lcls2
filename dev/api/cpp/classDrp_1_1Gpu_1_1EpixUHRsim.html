Detailed Description

Simulated GPU DRP detector for detType epixuhrsim (registered in PGPDetectorApp).

It wraps a SimDetector that replays 10 randomly generated events with random gain ranges, sets random pedestals and gains at BeginRun, and keeps reference calibrated results for checking.
