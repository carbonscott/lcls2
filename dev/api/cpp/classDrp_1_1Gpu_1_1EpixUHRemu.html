Detailed Description

GPU DRP detector for detType epixuhremu (registered in PGPDetectorApp).

It wraps an XpmDetector-based detector, allocates the calibration buffers and per-range pedestal and gain arrays, and names the raw data (array raw) in the Configure xtc.

Create the wrapped XpmDetector-based detector, the calibration buffers for NPixels pixels and device arrays of NRanges times NPixels pedestals and gains, which beginrun() fills.

Asserts that NPixels 16-bit values fit in a DMA buffer after the TimingHeader.
