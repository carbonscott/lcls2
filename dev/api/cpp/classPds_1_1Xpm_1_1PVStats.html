Detailed Description

Module-wide EPICS statistics PVs of an XPM; update() publishes rates computed from the change of the Module counters since the previous call.

Publish the PVs in the order allocate() created them: timing counter rates (clock counts scaled by 16e-6), PLL status, the XTPG time stamp, pulse ID and fiducial interval and error bit, per-link status and count changes, and the clocks scaled by 1e-6.

Each value is written only if its PV is connected.
