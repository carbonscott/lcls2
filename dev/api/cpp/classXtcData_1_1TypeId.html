◆ TypeId() [4/4]

XtcData::TypeId::TypeId ( const char *  )

Parse a string of the form "<name>_v<digits>", where <name> is one of name()'s strings.

On a match the code computes (version << 16) | type, which the 16-bit storage truncates to just the type, so the parsed version is dropped (version() returns 0). If there is no "_v" suffix, the digits are missing or followed by other characters, or the name is unknown, the value is NumberOf.
