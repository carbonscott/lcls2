Detailed Description

Parser for AxiStream batcher frames: splits a byte buffer into subframes by walking the subframe tails back from the end, and recursively parses subframes that are themselves batcher frames.

int eventBuilderParser::check_for_subframes ( )

Flag each frame as a nested batcher frame or not (by comparing its first two bytes with main_header) and parse the nested ones into sub_frames.

Returns 1, flagging none, if any frame is shorter than 2 bytes; otherwise 0.
