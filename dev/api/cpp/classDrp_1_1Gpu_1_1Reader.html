Detailed Description

Receives the FPGA DMA buffers on the GPU.

Each of nReaders streams runs a self-relaunching CUDA graph that, in turn with the other streams, waits for a DMA, takes the next pebble index, copies the DMA descriptor and TimingHeader to the pinned host write buffer and calibrates the payload into the calibration buffer. It then passes the buffer on through its reader queue and gives the DMA buffer back to the FPGA.
