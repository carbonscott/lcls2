Detailed Description

Runs the trigger primitive for each received buffer in a self-relaunching CUDA graph, taking buffers from the reader queues in turn and passing them to the host through a ring queue.

A receiver thread then checks each buffer's DMA descriptor and TimingHeader, fills in its PGPEvent and tells the collector how many buffers are ready.
