Detailed Description

Finds the MAC address of a host: first in /proc/net/arp, then by logging in to the device with telnet and reading the eth0 HWaddr from its ifconfig output.

◆ has()

bool Drp::JungfrauIdLookup::has ( const std::string &  hostname)

Return true if a MAC address is known for the IP address of hostname.

If it is not cached, /proc/net/arp is reloaded, and if still missing the device is queried over telnet (port 23).
