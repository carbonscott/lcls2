Append CreateData values taken from a header (pulse ID and timestamp; fifth argument) and an ETM record (rate flags, time slot, beam present and destination bits, sequence values; sixth argument).

Fields not taken from either (phase, charge, energy, wavelength, dmod5, MPS values, inhibit counts) are written as zeros.
