Detailed Description

View of one HSD channel: the constructor finds the raw (stream id 0) and fex (stream id 1) stream headers, waveform() returns the raw samples in place, and next_peak() iterates over the fex peaks.

Nothing is copied. The header comment refers to Hsd.hh for the data layout.
