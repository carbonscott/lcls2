Record one launch of the copy kernel.

In builds without HOST_LAUNCHED_REDUCERS it acts when *state is 1: it copies calibrated buffer *index to its data buffer, then the last block stores the size in bytes just before the data, writes 0 to the return code and sets *state to 2. The grid size depends on the threads per multiprocessor (1536 or 2048; other values abort).
