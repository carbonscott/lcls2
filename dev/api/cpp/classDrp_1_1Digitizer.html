Detailed Description

Detector for the high-speed digitizer (detType hsd per drp.cc), configured through the Python module psdaq.configdb.hsd_config with the EPICS prefix from the hsd_epics_prefix kwarg.

)
overridevirtual

Store the two TimingHeader words as eventHeader and copy each lane's payload (after the TimingHeader) into name index lane+1, then walk the stream headers of the payload.

Damage is increased (UserDefined) when bit 31 of the second word (JESD status, per the code comment) is clear, when a lane's size is at or above the strm_limit (that lane is skipped), or when a stream header reports unlocked; a stream header reporting overflow is logged as critical and aborts.

Implements Drp::Detector.
