Detailed Description

Iterates over the entries of a directory whose names contain a pattern; next() returns dirname + "/" + name.

Open dirname with opendir() (a WARNING is logged if that fails) and keep pattern (null means every entry).

Only the pointers are kept, and the default dirname is a hard-coded /reg/neh/home/dubrovin path.
