Detailed Description

Reducer that compresses each calibrated buffer with cuSZ (Lorenzo predictor, relative error bound 1.2e-4, Huffman coding).

It runs through reduce(), not a graph; its library targets are commented out in CMakeLists.txt and meson.build.
