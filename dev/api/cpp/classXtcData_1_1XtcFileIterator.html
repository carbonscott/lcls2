◆ next()

Dgram * XtcData::XtcFileIterator::next ( )

Read the next Dgram header (sizeof(Dgram) bytes) and then its xtc payload into the internal buffer.

Only a header read returning 0 is treated as end of file; failed or short header reads are not checked.

Returns
Pointer to the Dgram in the internal buffer (overwritten by the next call), or 0 at end of file, if header plus payload exceed maxDgramSize, or if the payload read fails or ends early (these last cases print a message).
