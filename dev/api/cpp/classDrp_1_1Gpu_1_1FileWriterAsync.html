Detailed Description

FileWriter that splits its GPU buffer into two halves: a filled half is written with cuFileWriteAsync on the registered stream while events are copied into the other half.

Like FileWriter::writeEvent but with two buffer halves: when the event does not fit in the current half or the batch is more than 2 seconds old, wait for the previous write, start a cuFileWriteAsync of the current half and switch halves.

Then copy the event device to device into the current half; exits if it does not fit or if an asynchronous write failed.
