How to read this page

  • Boxes are parts of the system. Click a box to zoom in: the map then shows the parts inside it, and the panel describes the part. A box drawn with a second edge behind it has parts inside; hover over a box to see its full title and summary.
  • Zoom out (or the Backspace or Escape key) goes up one level. The breadcrumb next to it shows where you are; click any of its names to jump back.
  • Arrows show what flows between the parts; the line style and colour give the kind of flow (see the legend under the map). Each label sits on its own arrow. Click a label to list, in the panel, every flow that the arrow stands for, with links to both ends; "(+N more)" means the arrow bundles several flows.
  • Arrows that end at the edge of the map lead to parts on another level. The rounded tag at the edge ("from …" or "to …") names that part; click it to go there.
  • Dashed boxes marked "Outside this repo" are mechanisms that are not implemented in this repository, such as firmware or facility services.
  • Tour follows one event step by step. Use Next and Previous, or the Left and Right arrow keys; Escape leaves the tour.
  • Read as one page shows the same content as one long document, for reading from top to bottom.
  • Edit this model is for the people who maintain this page: it explains how to change the underlying model file and check the change.
  • Links to other pages of the documentation (Documentation home, Edit this model and sources marked "This site") work on the built documentation site, not when this directory is served on its own.
